## 💻 CLI Operations Cheat Sheet

Below are the commands to execute migrations, linters, types, and server runs in this playground:

### 1. Database Migrations (Alembic)
*   **Generate an Autogenerated Revision:**
    ```powershell
    alembic revision --autogenerate -m "revision_message"
    ```
*   **Run All Pending Migrations:**
    ```powershell
    alembic upgrade head
    ```
*   **Rollback the Last Migration:**
    ```powershell
    alembic downgrade -1
    ```

### 2. Code Quality & Styling (Ruff)
*   **Run Linter Checks:**
    ```powershell
    ruff check .
    ```
*   **Auto-fix Lint Errors and Sort Imports:**
    ```powershell
    ruff check . --fix
    ```
*   **Format Source Files:**
    ```powershell
    ruff format .
    ```

### 3. Static Type Analysis (mypy)
*   **Run Type Checking:**
    ```powershell
    mypy .
    ```

### 4. Running the Dev Server
*   **Boot the Uvicorn ASGI Server:**
    ```powershell
    uvicorn app.main:app --reload --port 8000
    ```

## 📋 Declarative Model Comparison Cheat Sheet

Below is a side-by-side comparison of Pydantic API DTO models versus SQLAlchemy physical ORM models:

### 1. Pydantic DTO (Validation / Serialization)
*   **File Context:** [app/schemas/base.py](file:///c:/Users/Owner/Desktop/rewritepy2js/fastapi-realworld-example-app/app/schemas/base.py)
*   **Syntax Shape:**
    ```python
    from pydantic import BaseModel, ConfigDict
    
    class ArticleSchema(BaseModel):
        title: str
        description: str
        body: str
        
        # Enables ORM direct mapping (from_attributes=True replaces legacy orm_mode)
        model_config = ConfigDict(from_attributes=True)
    ```

### 2. SQLAlchemy ORM (Database Table Mapper)
*   **File Context:** [app/models/article.py](file:///c:/Users/Owner/Desktop/rewritepy2js/fastapi-realworld-example-app/app/models/article.py)
*   **Syntax Shape:**
    ```python
    from sqlalchemy import String, Text, ForeignKey
    from sqlalchemy.orm import Mapped, mapped_column, relationship
    from app.db.base import Base # Base inherits from DeclarativeBase
    
    class Article(Base):
        __tablename__ = "articles"
        
        id: Mapped[int] = mapped_column(primary_key=True)
        title: Mapped[str] = mapped_column(String, nullable=False)
        description: Mapped[str] = mapped_column(Text, nullable=False)
        author_id: Mapped[int] = mapped_column(ForeignKey("users.id"))
        
        # Declarative relationship mapping
        author: Mapped["User"] = relationship("User", back_populates="articles")
    ```
