# rewritepy2js CRUD upskill

This lesson follows the active TypeScript Express application in [`fastapi-realworld-example-app/src`](../fastapi-realworld-example-app/src), despite the project name and the candidate note's Python paths. The Python `app/api/routes/comments.py` files are commented scaffold, so they are not executable evidence. The live request is registered in [`routes/articles.ts`](../fastapi-realworld-example-app/src/routes/articles.ts), authenticated by middleware, and delegated to [`repositories/CommentRepository.ts`](../fastapi-realworld-example-app/src/repositories/CommentRepository.ts). Prisma's schema makes `Comment.article` a required relation and `Article.slug` unique.

The defect is a resource-boundary mismatch. `DELETE /articles/:slug/comments/:id` presents an article slug, while the old repository lookup used only `{ id }`. An author could send a valid comment ID under another article's slug and still delete it. The change passes the slug into `delete` and uses `findFirst` with `{ id, article: { slug } }`; ownership remains a second check. A wrong slug now behaves like a missing resource and reaches no delete call.

Read the [before snapshot](snapshots/CommentRepository.ts.original.txt), [route snapshot](snapshots/articles.ts.original.txt), and the [runtime test](../tests/comment-delete-boundary.test.mjs) beside the changed files. The test loads the exact TypeScript repository with the local VM loader and supplies a Prisma-shaped double. It verifies query arguments, delete calls, ownership failure, and route wiring. It does not claim an Express server or PostgreSQL execution. Work through the chapters in order: map the call chain, model the invariant, inspect the patch, predict traces, and use the review rubric in chapter 06.


A useful design habit is to name the invariant before editing: a comment can be deleted through this endpoint only when its id belongs to the requested article and its author is the authenticated user. The test cases each break one clause, making failures easy to localize. Compare the stored baseline with the staged file to see how a small signature change carries the invariant through the layers.
